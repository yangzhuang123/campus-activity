# 主办方活动管理系统 — 数据库表结构

> 对应测试文档涉及的 6 张核心数据库表

---

## 1. 主办方表 — `shezhang`

| 字段名 | 字段类型 | 描述 |
|--------|---------|------|
| id | bigint | ID（主键） |
| zhanghao | varchar | 账号 |
| mima | varchar | 密码 |
| shezhangxingming | varchar | 主办方姓名 |
| xingbie | varchar | 性别 |
| touxiang | varchar | 头像 |
| xueyuan | varchar | 学院 |
| banji | varchar | 班级 |
| shouji | varchar | 手机 |
| danweimingcheng | varchar | 单位名称（如学生会/XX系） |
| addtime | datetime | 创建时间 |

## 7. 标签表 — `tag`

**对应测试模块**：标签管理

| 字段名 | 字段类型 | 描述 |
|--------|---------|------|
| id | bigint | ID（主键，自增） |
| name | varchar(50) | 标签名称 |
| type | varchar(50) | 标签类型（活动标签、社团标签等） |

| create_time | datetime | 创建时间 |

---

## 8. 活动标签关联表 — `activity_tag`

**对应测试模块**：活动标签绑定

| 字段名 | 字段类型 | 描述 |
|--------|---------|------|
| id | bigint | ID（主键，自增） |
| activity_id | bigint | 活动ID（关联 shetuanhuodong.id） |
| tag_id | bigint | 标签ID（关联 tag.id） |

---

| 字段名 | 字段类型 | 描述 |

| create_time | datetime | 创建时间 |

## 表间关联关系

| 表名 | 关联字段 | 关联表 | 说明 |
|------|---------|-------|------|
| shetuanhuodong | zhanghao | shezhang.zhanghao | 活动所属主办方 |
| huodongbaoming | xuehao | xuesheng.xuehao | 报名学生 |
| huodongbaoming | biaoti | shetuanhuodong.biaoti | 报名关联活动 |
| storeup | userid | shezhang.id / xuesheng.id | 收藏用户 |
| storeup | refid | shetuanhuodong.id | 收藏的活动 |
| xiaoxi | yonghu | shezhang.zhanghao / xuesheng.xuehao | 消息接收用户 |
| activity_tag | activity_id | shetuanhuodong.id | 活动标签关联（多对多） |
| activity_tag | tag_id | tag.id | 标签关联（多对多） |
| discuss | user_id | shezhang.id / xuesheng.id | 评论用户 |
| discuss | object_id | shetuanhuodong.id | 被评论活动 |
