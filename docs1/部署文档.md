# 学生社团活动管理系统 - 部署文档

## 项目信息

- **项目名称**: 学生社团活动管理系统 (Student Club Activity Management System)
- **技术栈**: Spring Boot 2.2.2 + MyBatis-Plus + MySQL
- **端口**: 8080
- **上下文路径**: /springbootnp4n3

---

## 系统要求

### 必需软件

| 软件 | 版本要求 | 说明 |
|------|---------|------|
| JDK | 1.8+ | Java开发工具包 |
| Maven | 3.5+ | 项目构建工具 |
| MySQL | 5.7+ | 数据库服务器 |

### 推荐配置

- **CPU**: 2核心以上
- **内存**: 2GB以上
- **硬盘**: 500MB可用空间
- **操作系统**: Linux/Windows/macOS

## 部署步骤

### 1. 环境准备

#### 1.1 安装JDK

```bash

# macOS: brew install openjdk@8
```

```bash
# 检查Maven版本
mvn -version

# 如果未安装
# macOS: brew install maven
# Ubuntu: sudo apt-get install maven
```

#### 1.3 安装MySQL

```bash
# 检查MySQL状态
mysql --version
sudo systemctl status mysql

# 如果未安装
# macOS: brew install mysql
# Ubuntu: sudo apt-get install mysql-server
```

### 2. 数据库配置

#### 2.1 创建数据库

```sql
-- 登录MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE IF NOT EXISTS springbootnp4n3 
DEFAULT CHARACTER SET utf8mb4 
DEFAULT COLLATE utf8mb4_general_ci;

-- 使用数据库
USE springbootnp4n3;

-- 导入数据库脚本（如果有）
-- source /path/to/database.sql;
```

#### 2.2 配置数据库连接

编辑 `src/main/resources/application.yml`:

```yaml
spring:
    datasource:
        driverClassName: com.mysql.cj.jdbc.Driver
        url: jdbc:mysql://127.0.0.1:3306/springbootnp4n3?useUnicode=true&characterEncoding=utf-8&useJDBCCompliantTimezoneShift=true&useLegacyDatetimeCode=false&serverTimezone=GMT%2B8
        username: root
        password: 123456  # 修改为你的数据库密码
```

#### 4.2 后台运行（生产环境）

**Linux/macOS:**
```bash

nohup java -jar target/springbootnp4n3-0.0.1-SNAPSHOT.jar > app.log 2>&1 &

# 查看日志
```

**使用systemd（推荐）:**

创建服务文件 `/etc/systemd/system/springbootnp4n3.service`:

```ini
[Unit]
Description=Student Club Activity Management System
After=syslog.target network.target

[Service]
Type=simple
User=your_username
WorkingDirectory=/path/to/project
ExecStart=/usr/bin/java -jar target/springbootnp4n3-0.0.1-SNAPSHOT.jar
SuccessExitStatus=143
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启动服务:
```bash
sudo systemctl daemon-reload
sudo systemctl enable springbootnp4n3
sudo systemctl start springbootnp4n3
sudo systemctl status springbootnp4n3

# 查看日志
sudo journalctl -u springbootnp4n3 -f
```

**Windows (批处理脚本):**

创建 `start.bat`:
```batch
@echo off
set JAVA_HOME=C:\Program Files\Java\jdk1.8.0_181
set PATH=%JAVA_HOME%\bin;%PATH%
java -jar target\springbootnp4n3-0.0.1-SNAPSHOT.jar
pause
```

## 故障排除

### 常见问题

#### 1. 端口被占用

**错误:** `Port 8080 was already in use`

**解决:**
```bash
# 查找占用端口的进程
lsof -i :8080  # macOS/Linux
netstat -ano | findstr :8080  # Windows

# 停止进程或修改端口
kill -9 <PID>
```

#### 2. 数据库连接失败

**错误:** `Communications link failure`

**检查:**
```bash
# 测试MySQL连接
mysql -h 127.0.0.1 -u root -p

# 检查MySQL状态
sudo systemctl status mysql
```

**解决:**
- 确认MySQL正在运行
- 检查数据库名、用户名、密码
- 检查防火墙设置

#### 3. 编译失败

**错误:** `JAVA_HOME is not defined correctly`

**解决:**
```bash
# 确认JAVA_HOME指向JDK而非JRE
export JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk1.8.0_181.jdk/Contents/Home
echo $JAVA_HOME

# 验证
$JAVA_HOME/bin/java -version
```

#### 4. 内存不足

**错误:** `java.lang.OutOfMemoryError`

**解决:**
```bash
# 增加JVM内存
java -Xms512m -Xmx2048m -jar target/springbootnp4n3-0.0.1-SNAPSHOT.jar
```

## 监控和运维

### 健康检查

```bash
#!/bin/bash
# health_check.sh

URL="http://localhost:8080/springbootnp4n3"
RESPONSE=$(curl -s -o /dev/null -w "%{http_code}" $URL)

if [ $RESPONSE -eq 200 ]; then
    echo "Service is running"
    exit 0
else
    echo "Service is down, restarting..."
    # 重启服务逻辑
    exit 1
fi
```

### 定时任务（Cron）

```bash
# 编辑crontab
crontab -e

# 添加健康检查（每5分钟）
*/5 * * * * /path/to/health_check.sh >> /var/log/health_check.log 2>&1

# 添加日志轮转（每天）
0 0 * * * find /path/to/logs -name "*.log" -mtime +7 -delete
```
