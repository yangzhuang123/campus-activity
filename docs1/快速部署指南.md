# 快速部署指南

## 一键部署

### macOS / Linux

```bash
# 编译项目
./deploy.sh build

# 启动服务
./deploy.sh start

# 查看状态
./deploy.sh status

# 查看日志
./deploy.sh logs

# 重启服务
./deploy.sh restart

# 停止服务
./deploy.sh stop
```

### Windows

```batch
REM 编译项目
deploy.bat build

REM 启动服务
deploy.bat start

REM 查看状态
deploy.bat status

REM 重启服务
deploy.bat restart

REM 停止服务
deploy.bat stop
```

## 手动部署

### 编译命令
```bash
export JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk1.8.0_181.jdk/Contents/Home
mvn clean package -DskipTests
```

### 部署命令
```bash
java -jar target/springbootnp4n3-0.0.1-SNAPSHOT.jar
```

## 访问地址

启动成功后，访问以下地址：

- **后端API**: http://localhost:8080/springbootnp4n3
- **管理面板**: http://localhost:8080/springbootnp4n3/admin/admin/index.html
- **学生门户**: http://localhost:8080/springbootnp4n3/front/front/index.html

## 环境要求

- JDK 1.8+
- Maven 3.5+
- MySQL 5.7+

## 常见问题

**端口被占用**: 修改 `application.yml` 中的 `server.port`

**数据库连接失败**: 检查MySQL服务和数据库配置

**编译失败**: 确认JAVA_HOME指向JDK而非JRE
