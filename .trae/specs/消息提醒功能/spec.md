# 消息提醒功能规格说明书

## 概述

- **项目名称**: 消息提醒功能
- **文档目的**: 为社团管理系统添加消息提醒功能，实现学生和主办方（社长）的通知提醒
- **目标用户**: 学生（xuesheng）、主办方社长（shezhang）
- **优先级**: 高

## 需求背景

当前系统缺少消息通知机制，导致用户无法及时获取重要的活动相关信息。需要为学生和主办方分别提供定制化的消息提醒功能。

## 功能需求

### 学生端提醒

- **REM-1**: 报名通过提醒 - 当学生的活动报名被社长审核通过时，发送消息通知
- **REM-2**: 活动前1小时提醒 - 活动开始前1小时提醒已通过报名审核的学生

### 主办方（社长）端提醒

- **REM-3**: 成功发布提醒 - 当社长发布的活动成功上线时，发送消息通知
- **REM-4**: 报名已满提醒 - 当活动的报名人数达到上限时，通知社长
- **REM-5**: 活动前1小时提醒 - 活动开始前1小时提醒社长

## 消息通知前端展示

### 个人中心顶部消息图标

- 位置：个人中心页面头部，用户头像左侧
- 功能描述：
  - 鼠标悬停显示通知下拉面板
  - 显示未读消息数量角标
  - 点击单条消息标记为已读
  - 点击"查看全部"跳转消息列表页面

### 个人中心菜单

- 位置：社长/学生个人中心左侧菜单栏
- 功能描述：
  - 新增"消息通知"菜单项
  - 点击跳转至完整消息列表页面

## 消息表结构设计

### 数据库表：xiaoxi

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | bigint | 主键 |
| yonghu | varchar(200) | 接收人账号 |
| yonghutable | varchar(200) | 接收人表名 |
| xiaoxileixing | varchar(200) | 消息类型 |
| xiaoxibiaoti | varchar(500) | 消息标题 |
| xiaoxineirong | text | 消息内容 |
| fabushijian | datetime | 发布时间 |
| chushishijian | datetime | 触发时间 |

### 消息类型枚举

| 类型值 | 说明 |
|--------|------|
| baomingtongguo | 报名通过 |
| huodongqian1xiaoshi | 活动前1小时提醒 |
| fabuchenggong | 发布成功 |
| baomingyiman | 报名已满 |

## 技术实现要求

### 后端实现

1. 创建XxiaoxiEntity实体类及相关的DAO、Service、Controller
2. 修改HuodongbaomingController，在审核通过时插入消息
3. 修改ShetuanhuodongController，在发布成功时插入消息
4. 修改HuodongbaomingController，在报名已满时插入消息
5. 创建定时任务XiaoxiTimerTask，每小时执行一次检查活动前1小时提醒

### 前端实现

1. 修改个人中心页面（社长/学生），添加顶部消息通知组件
2. 创建消息通知列表页面pages/xiaoxi/list.html
3. 修改config.js，添加消息通知菜单项
4. 修改前台首页index.html，调用正确的消息接口

## 数据安全要求

- 用户只能查看自己收到的消息
- 按用户账号（yonghu）和用户表名（yonghutable）进行数据隔离

## 性能要求

- 定时任务每小时执行一次
- 消息列表查询需支持分页

## 约束条件

- 定时任务需要服务器保持运行
- 消息提醒依赖正确的系统时间
