# 社长个人中心功能规划

## 需求概述
为社长（shezhang）角色完善个人中心功能，包括个人信息展示与修改、我的发布、我的收藏、消息通知等模块。

## 当前状态分析
- **config.js**: 社长菜单已配置"个人中心"、"我的收藏"、"我的发布"
- **个人信息页**: 已存在但需要优化展示字段
- **我的发布页**: 不存在，需要创建
- **我的收藏页**: 已存在（storeup/list.html），但需要确保能正常取消收藏
- **消息通知**: 已实现基础框架，需要扩展为真正的后端通知数据

## 实施步骤

### 1. 优化社长个人信息页面 (`/pages/shezhang/center.html`)

**展示字段**：
- 学号 (zhanghao) - 只读
- 社长姓名 (shezhangxingming)
- 性别 (xingbie)
- 头像 (touxiang) - 支持上传
- 学院 (xueyuan)
- 班级 (banji)
- 手机 (shouji) - 支持修改
- 单位名称 (danweimingcheng)

**样式优化**：与学生个人中心风格保持一致

### 2. 创建社长"我的发布"页面 (`/pages/shezhang/mypublish.html`)

**功能**：
- 展示社长自己发布的活动列表
- 调用接口：`shetuanhuodong/list?zhanghao=当前账号`
- 点击活动卡片跳转详情页
- 详情页路径：`/pages/shetuanhuodong/detail.html?id=活动ID`

**样式**：卡片式布局，与"我的活动"风格一致

### 3. 确保收藏功能正常

**活动详情页收藏按钮**：
- 检查 `/pages/shetuanhuodong/detail.html` 中的收藏逻辑
- 确保调用 `storeup/add` 接口

**我的收藏页** (`/pages/storeup/list.html`)：
- 确保取消收藏功能正常
- 调用 `storeup/delete` 接口

### 4. 扩展消息通知系统

**通知类型**：
- 成功发布提醒：发布活动后
- 报名已满提醒：活动报名人数达到上限
- 活动前1小时提醒：定时任务或前端轮询

**实现方式**：
- 前端：从后端获取通知列表，调用 `news/list` 或新建通知表
- 后端：活动报名成功/满员时插入通知记录
- 定时提醒：前端轮询检查活动时间

### 5. 更新 config.js 菜单配置

确保社长菜单包含：
```javascript
{
    name: '个人中心',
    url: '../shezhang/center.html'
},
{
    name: '我的收藏',
    url: '../storeup/list.html'
},
{
    name: '我的发布',
    url: '../shezhang/mypublish.html'
}
```

### 6. 编译部署验证

- 执行 `mvn clean package -DskipTests`
- 重启 Spring Boot 应用
- 测试完整流程
