# 消息提醒功能实现计划

## 需求概述
为学生和主办方（社长）提供消息提醒功能：

### 学生提醒
- 报名通过提醒
- 活动前1小时提醒

### 主办方（社长）提醒
- 成功发布提醒
- 报名已满提醒
- 活动前1小时提醒

### 前端展示
1. **个人中心顶部消息通知图标**（头像左侧的铃铛图标）
   - 鼠标悬停显示通知下拉面板
   - 显示未读消息数量角标
   - 点击单条消息标记为已读
   - 点击"查看全部"跳转消息列表页面

2. **个人中心菜单新增"消息通知"菜单项**
   - 点击可查看完整消息列表

## 实现步骤

### 第一步：创建消息通知表（xiaoxi）

#### 1.1 数据库建表语句
```sql
CREATE TABLE `xiaoxi` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT COMMENT '主键',
  `yonghu` varchar(200) DEFAULT NULL COMMENT '接收人账号',
  `yonghutable` varchar(200) DEFAULT NULL COMMENT '接收人表名',
  `xiaoxileixing` varchar(200) DEFAULT NULL COMMENT '消息类型',
  `xiaoxibiaoti` varchar(500) DEFAULT NULL COMMENT '消息标题',
  `xiaoxineirong` text COMMENT '消息内容',
  `fabushijian` datetime DEFAULT NULL COMMENT '发布时间',
  `chushishijian` datetime DEFAULT NULL COMMENT '触发时间',
  `yuedu` varchar(200) DEFAULT '否' COMMENT '是否阅读',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8 COMMENT='消息通知表';
```

#### 1.2 创建实体类 XxiaoxiEntity.java
- 路径：`src/main/java/com/entity/XxiaoxiEntity.java`
- 包含字段：yonghu（接收人账号）、yonghutable（接收人表名）、xiaoxileixing（消息类型）、xiaoxibiaoti（消息标题）、xiaoxineirong（消息内容）、fabushijian（发布时间）、chushishijian（触发时间）、yuedu（是否阅读）

#### 1.3 创建视图类 XxiaoxiView.java
- 路径：`src/main/java/com/entity/view/XxiaoxiView.java`

#### 1.4 创建DAO接口 XxiaoxiDao.java
- 路径：`src/main/java/com/dao/XxiaoxiDao.java`

#### 1.5 创建Service接口和实现类
- Service接口：`src/main/java/com/service/XxiaoxiService.java`
- Service实现：`src/main/java/com/service/impl/XxiaoxiServiceImpl.java`

#### 1.6 创建Controller
- 路径：`src/main/java/com/controller/XxiaoxiController.java`
- 提供前端列表接口：`/xiaoxi/list`（按接收人账号和表名查询当前用户的消息）
- 提供更新已读接口：`/xiaoxi/update`

### 第二步：修改现有代码实现消息触发

#### 2.1 学生报名通过提醒
- 修改文件：`HuodongbaomingController.java`
- 修改方法：`update`（审核操作）
- 触发条件：当 `sfsh` 从"否"改为"是"时
- 消息内容：您的活动报名"XXX"已通过审核

#### 2.2 主办方成功发布提醒
- 修改文件：`ShetuanhuodongController.java`
- 修改方法：`publishNow`（立即发布）
- 触发条件：活动发布成功时
- 消息内容：您的活动"XXX"已发布成功

#### 2.3 主办方报名已满提醒
- 修改文件：`HuodongbaomingController.java`
- 修改方法：`save`（报名操作）
- 触发条件：当报名人数达到活动人数上限时
- 消息内容：您的活动"XXX"报名已满

### 第三步：实现活动前1小时定时提醒

#### 3.1 创建定时任务类
- 路径：`src/main/java/com/timer/XiaoxiTimerTask.java`
- 使用 `@Scheduled` 注解
- 每小时执行一次
- 查询条件：活动开始时间在当前时间+1小时内，且未发送提醒的活动
- 发送对象：活动的发布者（主办方）、已报名的学生

#### 3.2 修改启动类添加定时任务支持
- 修改文件：`SpringbootSchemaApplication.java`
- 添加 `@EnableScheduling` 注解

## 注意事项
1. 定时任务需要在服务器上保持运行才能执行
2. 活动前1小时提醒需要确保定时任务正常运行
3. 消息通知按用户账号和表名区分，确保不同角色看到各自的提醒
4. 个人中心菜单和顶部消息图标需要区分学生和社长角色
5. 消息类型包括：报名通过、活动前提醒、发布成功、报名已满
