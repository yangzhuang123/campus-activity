# 社长个人中心活动管理功能开发计划

## 需求概述
主办方的个人中心"我的发布"页面需要支持以下功能：
1. **活动发布**：填写标题、时间、地点、名额、简单介绍；上传1张封面图；有"保存草稿""立即发布"两个按钮
2. **活动管理**：已发布未开始的活动，支持修改信息、关闭报名
3. **数据统计**：在后台显示"已报名人数""剩余名额"

---

## 一、数据库变更

### 1. 社团活动表新增字段
```sql
USE springbootnp4n3;

-- 新增是否发布字段（草稿/已发布）
ALTER TABLE shetuanhuodong ADD COLUMN IF NOT EXISTS is_publish VARCHAR(20) DEFAULT '草稿' COMMENT '是否发布：草稿/已发布';

-- 新增报名状态字段（开放报名/已关闭）
ALTER TABLE shetuanhuodong ADD COLUMN IF NOT EXISTS baomingzhuangtai VARCHAR(20) DEFAULT '开放报名' COMMENT '报名状态：开放报名/已关闭';
```

---

## 二、实体类更新

### 1. 修改 ShetuanhuodongEntity.java
- 添加 `isPublish` 字段及其 getter/setter
- 添加 `baomingzhuangtai` 字段及其 getter/setter

---

## 三、后端接口

### 1. 修改 ShetuanhuodongController.java
新增接口：
- `saveDraft` - 保存草稿（不设置发布状态）
- `publishNow` - 立即发布（设置 isPublish='已发布'）
- `closeBaoming` - 关闭报名（设置 baomingzhuangtai='已关闭'）
- 修改 `detail` 接口 - 返回已报名人数和剩余名额

---

## 四、前端页面

### 1. 新增社长端活动发布页面
**文件**：`src/main/resources/front/front/pages/shezhang/huodong_add.html`

功能：
- 表单字段：标题、社团名称、活动图片、开始时间、结束时间、活动人数、活动地点、活动详情简介
- "保存草稿"按钮 - 调用保存草稿接口
- "立即发布"按钮 - 调用立即发布接口
- 活动图片上传限制为1张

### 2. 修改社长端我的发布页面
**文件**：`src/main/resources/front/front/pages/shezhang/mypublish.html`

功能：
- 显示已发布和草稿状态的活动
- 显示活动状态标签（草稿/已发布/已关闭）
- 显示已报名人数和剩余名额
- 支持修改信息按钮（跳转到编辑页面）
- 支持关闭报名按钮（仅对已发布且未开始的活动显示）

### 3. 新增社长端活动编辑页面
**文件**：`src/main/resources/front/front/pages/shezhang/huodong_edit.html`

功能：
- 编辑活动信息
- 支持重新上传封面图
- 保存后保持原发布状态

## 注意事项

- 活动状态流转：草稿 -> 已发布 -> 已关闭
- 已开始的活动的"关闭报名"按钮不显示
- 图片上传只允许1张
- 社长只能管理自己发布的活动
